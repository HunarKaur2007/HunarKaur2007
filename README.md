### 🟢 Featured Projects

<details>
<summary><b>🛠️ Citizen Grievance Redressal & Escalation Management System (CGR-EMS)</b></summary>

A database-driven system for managing the full grievance lifecycle — registration, assignment, escalation, resolution, and feedback — built with Oracle SQL & PL/SQL, paired with a basic web interface for citizen interaction.

| Aspect | Details |
|---|---|
| Stack | SQL, PL/SQL, Oracle Database, HTML/CSS/JS |
| Scale | 6 normalized entities — Citizen, Grievance, Department, Officer, Escalation, Feedback |
| Performance | ER-modeled schema normalized to 3NF with PK/FK relationships across all tables |
| Security | Data integrity via PK/FK, UNIQUE & CHECK constraints, ACID-compliant transactions (COMMIT/ROLLBACK) |
| Impact | Automated grievance escalation via PL/SQL triggers, feedback validation, and reporting via JOIN/GROUP BY queries |
| Repository | [github.com/HunarKaur2007](https://github.com/HunarKaur2007) |

Designed an ER model and converted it into a 3NF relational schema with stored procedures (e.g. `Insert_Grievance`) for structured data entry and an `AFTER UPDATE` trigger that auto-creates escalation records when a grievance status changes to "Escalated." A `BEFORE INSERT` trigger on Feedback enforces that feedback can only be submitted after resolution. A companion frontend (login-free demo UI) allows citizens to register and track complaints by ID. Built collaboratively with Bismanjot Singh and Jasmeh Singh Sodhi at TIET.

</details>

<details>
<summary><b>🛠️ AEC-DT — Autonomous Energy Community Digital Twin</b></summary>

A real-time multi-agent digital twin simulating an autonomous energy community, combining live weather data, physics-based modeling, and reinforcement learning agents for grid-aware energy management.

| Aspect | Details |
|---|---|
| Stack | Python, PyTorch (DQN/PPO), Flask/FastAPI backend, Leaflet.js, HTML/CSS/JS dashboard |
| Scale | 5 coordinated agents (PV, Voltage, Battery, EV, Cyber) across an IEEE 33-bus distribution network |
| Performance | Live Open-Meteo weather + irradiance forecasting, Kalman filtering, Newton-Raphson power flow, PINN-based modeling |
| Security | Dedicated Cyber Agent for grid integrity & anomaly monitoring |
| Impact | Real-time multi-agent decisions (e.g. grid stress detection → EV charging deferral → battery support activation) visualized on a live map dashboard |
| Repository | [github.com/HunarKaur2007](https://github.com/HunarKaur2007) |

Built a multi-agent system (MAS) where a PV Agent (250 kW solar), Voltage Agent (IEEE 33-bus), Battery Agent (500 kWh BESS), EV Agent (smart charging with V2G), and Cyber Agent communicate over an MCP-based optimizer to coordinate grid operations. Integrates DQN and PPO reinforcement learning agents, federated averaging (FedAvg), forecast agents driven by NASA POWER and Open-Meteo APIs, and physics solvers (Newton-Raphson, PINN, Kalman filter) for accurate, location-agnostic grid simulation — all rendered live on an interactive Leaflet map dashboard.

</details>
